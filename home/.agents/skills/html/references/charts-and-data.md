# Charts and data

Use this when quantitative comparisons are central. Start with the comparison the viewer needs to make, then choose a chart:

- change over time: line, area, or aligned small multiples;
- ranked magnitude: ordered bars or a table with visual emphasis;
- part to whole: stacked bars when the denominator is meaningful;
- distribution: histogram, dot plot, box plot, or density view;
- relationship: scatter plot with meaningful scales and annotations;
- flow: Sankey or network only when path magnitude is the point.

Use a table when exact values matter more than shape. A chart and compact table can coexist when they serve different reading needs.

## Keep the data honest

- Label units, time ranges, sources, and important filters.
- Choose scales that support the comparison; disclose truncation and nonlinear scales.
- Distinguish measured values, estimates, targets, and forecasts in text and presentation.
- Never invent data to fill visual space. Mark illustrative or missing values plainly.
- Keep categories distinguishable without color alone, and separate status colors from the general palette.
- Contain dense data horizontally rather than compressing labels until they are illegible.

Tooltips may add precision but must not carry essential facts or conclusions. Show active filters and a clear reset. Provide an accessible summary or table when values would otherwise be available only through pointer interaction. Animate only to explain a meaningful change.
