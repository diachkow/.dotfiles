# Creative direction

Use this when the user or project has not already supplied a visual direction.

## Start with the subject

Find one organizing idea in the subject's materials, tools, environment, notation, audience, or language. Let it shape composition, type, information rhythm, imagery, or interaction.

Choose a fitting register:

- **Workmanlike:** restrained color, clear hierarchy, direct copy; suited to plans, reports, and operational tools.
- **Editorial:** deliberate pacing, distinctive type, and one memorable visual move; suited to explainers, launches, and presentations.
- **Expressive:** immersive visual or interaction treatment; reserve for work where the experience itself carries meaning.

Before writing CSS, make a short plan for composition, hierarchy, palette roles, typography, density, and any motion or interaction. Don't impose quotas for colors, typefaces, columns, or components.

## Keep the design specific

- Follow the user's reference or the project's design system before applying personal taste.
- Treat cards, pills, gradients, oversized numerals, rails, and labels as structural devices, not default decoration.
- A new palette on the same generic layout is not a distinct direction. Vary composition or information rhythm when the subject calls for it.
- Use system fonts when they fit. Add embedded fonts only when their value justifies the added size and their license permits it.
- Keep status colors distinct from the decorative accent; do not encode meaning by color alone.
- Use motion only when it explains change or gives useful feedback. Respect `prefers-reduced-motion`.

Choose a considered direction and finish it; restraint should still feel intentional.
