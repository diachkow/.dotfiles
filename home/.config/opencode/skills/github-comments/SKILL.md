---
name: github-comments
description: Use this skill EVERY TIME you are about to leave the comment on Github.
---

You can leave comments on Github on user's behalf via `gh` CLI tool. You must prefix all the comments with the following part:

```
> [!NOTE]
> <model_name> is commenting on behalf of Vitalii
```

After that, paste the actual comment contents. Don't forget to fill in the `<model_name>` part.
